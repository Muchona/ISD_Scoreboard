# Annealing Log — ISD Scoreboard

Lessons captured under the Self-Annealing Loop (Onyx Protocol §2). Read before touching the related area.

| # | Area | Error / Symptom | Root Cause | Fix | Prevention Rule |
|---|------|-----------------|------------|-----|-----------------|
| 1 | Tailwind v4 / Theming | Dark/light toggle did nothing; `dark:` styles followed the OS theme | Tailwind **v4 ignores** `darkMode: 'class'` in `tailwind.config.js` (the config file isn't loaded by default) | Added `@custom-variant dark (&:where(.dark, .dark *));` to `src/index.css`; deleted unused config | **Tailwind v4 projects: configure in CSS (`@theme`, `@custom-variant`), never `tailwind.config.js`.** Verify with: compiled CSS contains `:where(.dark` and no `prefers-color-scheme:dark`. |
| 2 | Tailwind v4 / Build | `postcss` error: "trying to use tailwindcss directly as a PostCSS plugin" | v4 moved the PostCSS plugin to `@tailwindcss/postcss` | Use `@tailwindcss/vite` plugin; removed `postcss.config.js` | With Vite, use `@tailwindcss/vite` only. No PostCSS config needed. |
| 3 | Vite / ESM | Warnings: ESM config loaded as CommonJS | `package.json` lacked `"type": "module"` | Added `"type": "module"` | Set `"type": "module"` at scaffold time. |
| 4 | TypeScript / pdf-lib | `Uint8Array<ArrayBufferLike>` not assignable to `BlobPart` | Newer TS DOM lib types are stricter about `SharedArrayBuffer` | `new Blob([bytes.buffer as ArrayBuffer])` | Cast pdf-lib output buffers when constructing `Blob`s. |
| 5 | Theming / First paint | Dark-mode users would see a white flash on load | Theme class applied only after React mounted | Inline script in `<head>` applies `.dark` from `localStorage` before paint | Every themed project needs the pre-paint theme script. |
| 6 | Content accuracy | Placeholder ISD point values (Type A/B/C, 70/50/30) shipped in the UI | Demo data written from memory, not verified | **RESOLVED & VERIFIED**: Rebuilt `isdPointsTable.ts`, `ScorecardBento.tsx`, `DaysCalculator.tsx`, and `RequirementsHub.tsx` from official ISD source (`https://www.irishimmigration.ie/how-to-become-a-citizen/become-an-irish-citizen-by-naturalisation/proofs-of-identity-and-residence/`). Identity: Valid in-date passport = 150 points proven once. Residence: Exactly 1 Type A (100 pts) + 1 Type B (50 pts) = 150 pts/year. Section 15C absences: 70d standard + up to 30d exceptional (100d hard cap). | **Every legal/government figure must be verified against an official source URL before entering the codebase.** |
| 7 | Theme toggles | Hard-coded `text-white` brand elements become invisible in light mode | Components ported from dark-only projects | Ported `OnyxBadge` with `dark:` variants | When porting from Onyx (dark-only) projects, audit every hard-coded white/black colour. |
| 8 | Brand Identity | Balancing Onyx & Code studio identity with civic client product | Luxury black/gold can reduce civic trust for immigration tools | Keep civic Emerald (`#00875A` / `#10B981`) primary palette for CitizenScore.ie; keep `OnyxBadge` at bottom-right of footer as the Onyx signature linking to onyxandcode.com. | Client-facing public-service products use domain-appropriate trust colors, with Onyx signature in footer. |
| 9 | Badge & Table Alignment | Mismatched header pill heights, broken 2-line chip wrapping in tables | `.chip` and `IsdCitation` had differing heights, radii (`rounded-full` vs `rounded-lg`), and padding; table cells lacked `whitespace-nowrap` causing text like "IDENTITY SECONDARY" to break into 2 lines | Standardized `.chip` and `IsdCitation` to fixed `h-7`, `rounded-full`, and `whitespace-nowrap`; formatted classification chips cleanly (`Primary ID`, `Alternative ID`, `Type A [100 pts]`, `Type B [50 pts]`); added explicit column widths and `min-w-[760px]` to schedule table | **Paired badge/pill components must share identical heights (`h-7`), corner radius, and `whitespace-nowrap`. Table status chips must never wrap.** |
| 10 | Calculator Input Method | Manual duration input in days instead of date ranges | Prototype asked users to manually calculate and type day numbers (e.g. `180`) | **Rebuilt like the official ISD calculator**: Target Application Date + chronological Start Date (`From`) and End Date (`To`) with automatic day computation, statutory 9-year/5-year window validation, and Section 15C final year checks, wrapped in our modern UI. | **Immigration calculations must accept calendar date ranges (From/To), not require users to manually count days.** |
| 11 | Demo Video Walkthrough | "Watch 60-Sec Demo" opened a static text card dialog with no video | Modal contained static text tabs rather than an actual video or animated software simulation player | Built dedicated `DemoVideoPlayer.tsx` featuring a full 16:9 media player with live animated software simulation (0:00 to 1:00 timeline, scrubber bar, play/pause, chapter jumping across Days, Scorecard, and Watermarker) + dual-mode switch to official Irish naturalisation video guide | **If a UI button promises "Watch Demo Video", never present static text cards. Provide a genuine video player with playable interactive simulation or official video stream.** |
| 12 | Video Player Light/Dark Theming | Video player forced dark theme even when Light Mode was active | Hard-coded dark classes (`bg-slate-950`, `text-white`, dark gradient canvas) inside `DemoVideoPlayer.tsx` and modal backdrop | Rebuilt `DemoVideoPlayer.tsx` and modal backdrop with complete light and dark mode variants (`bg-white dark:bg-slate-950`, light slate viewport canvas, themed controls and cards) so the player dynamically respects the theme toggle | **Every interactive modal and embedded media player must support both Light and Dark modes symmetrically.** |
| 13 | Irish Tricolour Brand Elements | Hero buttons and top badges missed opportunity for iconic Irish tricolour aesthetic | Action buttons were green / white / gray ghost; top citations were green and blue | Styled the 3 hero action buttons as the Irish Tricolour: 1.
